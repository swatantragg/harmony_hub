01 — Positioning

A control room that feels like a concert hall

Maestro is where a music company keeps every master, cover, video, reel and lyric for a release — searchable, versioned, and always accounted for. The Nocturne direction dresses that power in restraint: deep surfaces so artwork and waveforms carry the colour, and a single brass accent for the moments that matter.

Composed
Calm, layered, unhurried. Nothing shouts; the interface holds still so the work stands out.
Premium
Brass, deep neutrals and an editorial serif signal craft and permanence — this holds irreplaceable masters.
Precise
Every S3 key, checksum and version is legible and exact. Trust is built on detail.
Assured
The system always knows what it holds and whether it's really there. Quiet confidence, never anxiety.

02 — Logo & wordmark

The mark

A five-bar equaliser set in a rounded tile — audio made visible, and a downbeat that reads as leadership. The wordmark is set in Fraunces, the serif giving “Maestro” its classical, conductor’s gravity.

Maestro

Clear space & sizing

Keep clear space equal to the height of the tile on every side. Minimum tile size is 24 px on screen; below that, use the tile alone without the wordmark.

Maestro

Usage rules

  • ✓ Brass bars on a dark tile is the primary lockup.
  • ✓ On light surfaces, use the deep-brass tile with ink bars.
  • ✕ Never recolour the wordmark or add a gradient.
  • ✕ Never stretch, rotate, or add a drop shadow.
  • ✕ Never set the wordmark in the UI sans (Inter).

03 — Colour

Obsidian & brass

The palette is 90% neutral by design. Deep, faintly warm darks form four elevation levels; brass is spent sparingly on primary actions, focus, and brand moments. A muted steel blue is the only cool note, reserved for links and information.

04 — Typography

Three voices, clear roles

A high-contrast serif for brand and headlines, a neutral grotesque for the working interface, and a monospace for the technical truth — keys, hashes, sizes and IDs. The serif appears only at large sizes and brand moments; it never runs a data table.
